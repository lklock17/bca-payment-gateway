Pengenalan

Selamat datang di **BCA Payment Gateway API**. Gateway pembayaran mandiri ini memungkinkan website e-commerce atau aplikasi toko online Anda untuk memproses pembayaran QRIS secara langsung menggunakan akun KlikBCA Merchant Anda.

Alur kerja sistem ini sangat sederhana:

  1. Aplikasi toko online Anda mengirimkan nominal belanja ke API ini.
  2. API menambahkan kode unik nominal kecil (sebagai fee/suffix antara 1-199 rupiah) untuk keperluan verifikasi.
  3. API memodifikasi QRIS statis merchant Anda menjadi QRIS dinamis ber-nominal secara offline dan mengembalikan gambar QR code.
  4. Pembeli memindai QRIS dan melakukan pembayaran.
  5. Sistem standby scraper kami mendeteksi mutasi masuk di rekening KlikBCA secara real-time dan mencocokkan nominal transaksi secara otomatis.
  6. API mengirimkan webhook instan ke url toko online Anda untuk mengonfirmasi pembayaran sukses.

Autentikasi

Setiap request ke endpoint API ini harus melampirkan **API Key** yang valid dalam header HTTP request sebagai **Bearer Token**.

API Key didapatkan dari halaman Dashboard Admin setelah Anda menambahkan Akun BCA Merchant Anda.

Format Header Otorisasi: Authorization: Bearer BCA-GW-YOUR_MERCHANT_API_KEY

Charge API (Buat Invoice QRIS)

Gunakan endpoint ini untuk membuat invoice pembayaran baru. API akan mengembalikan payload data QRIS dinamis beserta gambar barcode Base64.

POST /api/v1/charge

Parameter Body (JSON)

Field Tipe Status Deskripsi
external_id String Wajib ID unik transaksi dari sistem toko online Anda (contoh: ORDER-100249).
amount Number Wajib Nominal dasar pembayaran. Harus bernilai positif dan bulat.
webhook_url String Opsional URL callback di server Anda yang akan dikirimi notifikasi sukses otomatis.

Respons Payload (JSON) - 201 Created

API akan menambahkan suffix nominal acak (1-199 rupiah) yang disimpan dalam variabel fee untuk membedakan transaksi nominal kembar. Jumlah akhir yang harus dibayar adalah total dari amount (amount + fee). 

{
  "status": "pending",
  "transaction_id": 18,
  "external_id": "ORDER-100249",
  "amount": 10103,
  "base_amount": 10000,
  "fee": 103,
  "qris_string": "0002010102125144...",
  "qris_image": "data:image/png;base64,iVBORw0KGgo...",
  "created_at": "2026-06-05T14:53:45.000Z"
}

Status API (Cek Pembayaran)

Gunakan endpoint ini untuk melakukan pengecekan manual status transaksi dari backend Anda secara berkala (*polling*).

GET /api/v1/status/:external_id

Respons Payload (JSON) - 200 OK

{
  "external_id": "ORDER-100249",
  "status": "success",
  "amount": 10103,
  "created_at": "2026-06-05T14:53:45.000Z",
  "updated_at": "2026-06-05T14:55:00.000Z"
}

Webhook Callback

Ketika pembeli menyelesaikan transaksi dan scraper berhasil mencocokkan mutasi rekening, gateway akan mengirimkan HTTP POST request berisi detail pembayaran ke URL webhook_url yang dikonfigurasi saat membuat charge.

Sistem akan mengulangi pengiriman webhook hingga 3 kali dengan jeda waktu 2 detik jika server Anda mengembalikan respons selain HTTP 200 OK.

Payload Webhook Callback (JSON)

{
  "transaction_id": 18,
  "external_id": "ORDER-100249",
  "amount": 10103,
  "status": "success",
  "updated_at": "2026-06-05T14:55:00.000Z"
}

Contoh Integrasi Kode

Gunakan contoh snippet kode berikut untuk mengintegrasikan toko online Anda dengan gateway pembayaran ini.

# Membuat invoice transaksi curl -X POST http://IP_VPS_ANDA:3005/api/v1/charge \ -H "Authorization: Bearer BCA-GW-YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "external_id": "ORDER-100249", "amount": 10000, "webhook_url": "https://website-anda.com/webhook" }' # Memeriksa status transaksi curl -X GET http://IP_VPS_ANDA:3005/api/v1/status/ORDER-100249 \ -H "Authorization: Bearer BCA-GW-YOUR_API_KEY"
<?php // Contoh Request Charge API di PHP $url = "http://IP_VPS_ANDA:3005/api/v1/charge"; $apiKey = "BCA-GW-YOUR_API_KEY"; $payload = [ "external_id" => "ORDER-100249", "amount" => 10000, "webhook_url" => "https://website-anda.com/webhook" ]; $ch = curl_init($url); curl_setopt($ch, CURLOPT_RETURNTRANSFER, true); curl_setopt($ch, CURLOPT_POST, true); curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($payload)); curl_setopt($ch, CURLOPT_HTTPHEADER, [ "Authorization: Bearer " . $apiKey, "Content-Type: application/json" ]); $response = curl_exec($ch); curl_close($ch); $data = json_decode($response, true); if (isset($data['qris_image'])) { // Tampilkan QRIS ke pembeli echo '<img src="' . $data['qris_image'] . '" alt="QRIS" />'; } ?>
const axios = require('axios'); async function createCharge() { try { const response = await axios.post('http://IP_VPS_ANDA:3005/api/v1/charge', { external_id: 'ORDER-100249', amount: 10000, webhook_url: 'https://website-anda.com/webhook' }, { headers: { 'Authorization': 'Bearer BCA-GW-YOUR_API_KEY', 'Content-Type': 'application/json' } }); console.log('Nominal Akhir (+Fee):', response.data.amount); console.log('Base64 QRIS Image:', response.data.qris_image); } catch (error) { console.error('Error creating charge:', error.response ? error.response.data : error.message); } } createCharge();
